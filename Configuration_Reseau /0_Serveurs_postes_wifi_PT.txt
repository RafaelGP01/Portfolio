2) Services (onglet Services)
Principe du moindre service : sur chaque Server-PT, coupe tout ce qui ne sert pas
(HTTP/HTTPS sont actifs par defaut partout).

AEGIS-DC01   : DNS ON, DHCP ON, NTP ON, le reste OFF
  DHCP > nouveau pool :
    Pool Name        POSTES
    Default Gateway  172.16.30.254
    DNS Server       172.16.20.10
    Start IP         172.16.30.100
    Subnet Mask      255.255.255.0
    Maximum Users    100
    -> Add
  DNS > enregistrements A :
    dc01.aegis-capital.local     172.16.20.10
    fs01.aegis-capital.local     172.16.20.11
    crm.aegis-capital.local      172.16.20.12
    glpi.aegis-capital.local     172.16.20.14
    www.aegis-capital.fr         172.16.40.10   (DNS interne : les postes vont direct en DMZ)
    espace.aegis-capital.fr      172.16.40.10   (reverse proxy Nginx sur WEB01)

AEGIS-SIEM01 : SYSLOG ON (+ NETFLOW si ta version de PT le propose), le reste OFF
AEGIS-WEB01  : HTTP ON, HTTPS ON -> modifie index.html (page vitrine Aegis Capital)
AEGIS-APP01  : HTTP ON, HTTPS ON -> page "Espace investisseur"
AEGIS-CRM01  : HTTPS ON -> page "SuiteCRM"
AEGIS-GLPI01 : HTTPS ON -> page "GLPI"
AEGIS-FS01, AEGIS-SQL01, AEGIS-BKP01 : tout OFF (PT ne simule pas SMB/MariaDB/PBS)

3) Wi-Fi
Renomme "Access Point0" en AEGIS-AP01.
AEGIS-AP01 > Config > Port 1 :
  SSID AEGIS-CORP / WPA2-PSK / passphrase forte / Encryption AES
Chaque laptop > Config > Wireless0 :
  meme SSID, WPA2-PSK, meme passphrase, AES
  puis Desktop > IP Configuration > DHCP -> doit recevoir 172.16.30.1xx
